プライバシーポリシー

在庫スキャナ（以下「本アプリ」）／制定日：2026年11月6日

本アプリの運営者（以下「運営者」）は、本アプリの利用者の情報を、以下のとおり取り扱います。本アプリは、iPhone アプリ版と Web 版（ブラウザで使う版）で同じ取り扱いをします。

1. 端末の中だけに保存する情報（運営者には送られません）

  • 登録した商品の情報（バーコード、商品名、メーカー、色番号、容量、仕入れ値、保管場所、メモなど）
  • 在庫数、入出庫・利用の履歴、設定（リセット日、在庫の色分けなど）

これらは利用者の端末（アプリ内、またはブラウザ内）にだけ保存され、運営者を含む外部には送信されません。本アプリを削除するか、ブラウザのサイトデータを消去すると、これらの情報も削除されます。CSV 出力した場合は、利用者が選んだ共有先に送られます。

2. カメラ

バーコードを読み取るためにカメラを使用します。カメラの映像は端末の中でバーコードの読み取りにだけ使い、保存や送信はしません。

3. 共有マスタ（任意の機能）で取り扱う情報

「共有マスタ」は、JAN コードと商品名の対応を利用者みんなで共有する任意の機能です。候補を見るだけなら、ログインも情報の送信も不要です（JAN コードだけを送って候補を受け取ります）。登録や通報をするには、メールアドレスでのログインが必要です。

情報取得する場面利用目的
メールアドレスログインするとき本人確認（確認コードの送信）、不正な利用への対処
利用者 ID（自動で割り当てる番号）ログインするとき登録・通報がだれによるものかの区別、1日の件数制限
JAN コード、商品名、メーカー名商品を保存し、共有する設定がオンのとき共有マスタの候補として、ほかの利用者に表示するため
通報の内容と理由候補を通報したとき不適切な登録の確認と対処
操作の日時上記の各操作のとき件数制限、不正な利用への対処
  • 公開される情報：登録した商品名・メーカー名と、その名前を登録した人数は、ほかの利用者に公開されます。メールアドレスは公開されません。
  • 運営者は、不正な利用への対処のため、登録した人のメールアドレスを確認することがあります。

4. 外部のサービス

  • Supabase（Supabase, Inc. が提供するクラウドサービス）：共有マスタのデータとログインの管理に使います。上記 3 の情報は Supabase のサーバーに保存されます。
  • メール送信サービス：ログイン用の確認コードをメールで送るために使います。
  • Open Food Facts：商品名の候補を調べるため、読み取った JAN コードを送信します（JAN コード以外は送りません）。
  • Web 検索：「Web で検索」ボタンを押すと、JAN コードを検索語としてブラウザで検索サイトを開きます。

本アプリは、広告の配信、利用状況の分析（アクセス解析）、他社のアプリやサイトをまたいだ追跡（トラッキング）を行いません。法令に基づく場合を除き、取得した情報を第三者に提供・販売しません。

5. 保存期間と削除

  • 共有マスタの情報は、利用者がアカウントを削除するまで保存します。
  • アカウントの削除：本アプリの「設定」タブ →「共有マスタ」→「アカウントを削除」から、いつでも削除できます。削除すると、メールアドレス、利用者 ID、その人の登録・通報が削除されます（元に戻せません）。運営者の対応の記録には、操作の内容が残ることがあります。
  • 共有マスタへの登録だけをやめたい場合は、「設定」タブの「登録時に共有する」をオフにしてください。
  • アプリから削除できない場合は、下記の連絡先にご連絡ください。

6. 安全管理

通信は暗号化（HTTPS）します。共有マスタのデータは、利用者が直接読み書きできないよう権限を設定し、運営者用の機能は運営者のアカウントに限っています。
